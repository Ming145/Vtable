# Vtable

[English](README.md) | 中文

[Obsidian](https://obsidian.md) 增强可编辑表格。在 ```vtable 代码块中创建表格，直接在实时预览里编辑单元格，能力远超原生 Markdown 表格：格内换行、合并单元格、Excel 风格公式，甚至 **原生表格放不下的可勾选任务列表**——外加图片、数学公式、图表与一键导出。

开箱即美：简洁克制的设计、自动适配主题的配色，以及高度的自定义能力——单表线风格、隔行变色、表头颜色、单元格对齐与底色，一切都能调整成你仓库的样子。

支持桌面端、iPad 与手机。

## 功能

### 丰富的单元格内容

在单元格里输入的内容，失焦后按 Obsidian 预览效果渲染：

- Markdown 行内样式：`**加粗**`、`*斜体*`、`==高亮==`、`~~删除线~~`、`` `代码` ``、`[链接](url)`
- Obsidian 嵌入：`![[图片.png]]` 和 `![[图片.png|300]]` —— 编辑态拖动图片角点即可调整尺寸，宽度语法自动同步
- 行内数学公式：`$E=mc^2$`
- 可勾选任务列表：`- [ ]` / `- [x]` —— 预览模式点击复选框，源码同步更新
- Markdown 不够用时可直接手写 HTML（如字号、颜色）

### 结构

- 右合 / 下合 / 拆分，单格或整个选区
- 任意位置插入与删除行列
- 拖动行头/列头重新排序
- 跳越式导航：Tab、Enter 与方向键正确跨越合并单元格
- 快速追加：光标位于最后一行/最后一列时，表格底部/右缘出现 `+` 条，点击即加一行/一列

### 选区与批量操作

- `Ctrl/Cmd+Shift` + 点击开始框选，拖动出橡皮筋选区
- 双击单元格选中它；移动端双击累积选区
- 批量加粗、斜体、字号、对齐（左/中/右）、底色，或清空内容
- 单击行/列拖动符（不滑动）选中整行/整列；`Shift`+点击可追加进选区
- `Ctrl/Cmd+Delete` 删除整行/整列选区对应的行/列

### 网格复制粘贴

把矩形区域复制为 Markdown 表格，再把任意 Markdown 表格粘回网格——跨表格、跨笔记，甚至跨应用：

- 有选框时按 `Ctrl/Cmd+C`，选区导出为标准 Markdown 表格（`| a | b |` 含分隔行）
- 点击一个单元格后按 `Ctrl/Cmd+V` 粘贴 Markdown 表格：以点击格为左上角写入网格。已有内容直接覆盖；超出当前行列范围的部分被丢弃（不自动加行列）
- `Ctrl/Cmd+Alt+V` 同样粘贴，但会自动补足整行/整列，完整放入剪贴板内容
- 任意两张 vtable 之间（同笔记或不同笔记）均可互通，也接受从别处复制的 Markdown 表格。粘贴普通文本保持原有单格行为

### 序列填充（桌面端）

选中单元格，拖动其右下角出现的小三角，沿行或列拖：

- 纯文本被复制；纯数字按增量填充（填充末端附近的小弹窗可在递增/递减之间切换方向）
- 文本+数字混合时保留文字、数字递增（`条目1、条目2、…` / `Item 1, Item 2, …`）
- 日历感知循环：星期（`星期一…` / `Monday…`）、月份（`一月…` / `January…`）按周期循环；日期按真实日历推进，闰年正确处理
- 日期多格式（中英写法都认）：`2027年2月28日`、`2027-02-28`、`2027/2/28`、`2027.2.28`、`2/28`、`02-28`（首数大于 12 时按日前置解读，如 `28/2`）、`March 1`、`Mar 1`、`1 March`、`March 1, 2027`、`1 March 2027`；带年份的按数据本身的年份判闰并跨年自动进位——非闰年不会出现 `2月29日`，跨过 12月31日 后年份递增；无年份的按当年日历循环；填充输出保持输入的书写风格（分隔符、补零、月名全称/缩写、逗号）

### 斜分单元格

**斜分单元格**命令在焦点格（或选区格）内画出左上→右下的对角线，把单元格分成两个单行输入区——右上与左下。若格内已有文字，文字移入左下区。按 Enter 或方向键可在两区之间跳转并跳出单元格。

### 表格样式预设

除圆角与表头底色外，每张表可套用三种线型预设之一，外加隔行变色：

- **三线表** —— 顶线、表头下线、底线；无竖线
- **无格线** —— 移除所有单元格边框
- **仅横线** —— 保留顶/底边与行分隔线，去掉竖线
- **隔行变色** —— 按主题强调色或自定义颜色逐行填色；单格底色始终优先。启用表头底色时从第 3 行开始

预设通过设置作用于整个仓库，或用 **表格样式调用**、**删除表格样式**、**隔行变色样式** 命令对单表生效（单表覆盖随表格存储）。样式仅作用于显示：编辑单元格时恢复原始外观。

### 三种显示模式

随时通过表格上方的模式按钮切换，选择按表格存储。

- **OL**（默认）—— 单元格自由换行，高度自适应
- **HS** —— 单元格横向拉伸不换行，带可拖动自定义滚动条
- **RC** —— 固定列宽行高，配专用拖动手柄；内容溢出时行高自动增长

### Excel 风格公式

以 `=函数(范围)` 开头的单元格显示计算结果，重新聚焦时显示原公式供编辑。支持的函数：

```
=SUM(A1:A5)   =AVERAGE(B1:B3)   =COUNT(C1:C9)   =MIN(A1:A9)   =MAX(A1:A9)
```

### 图表

把表格数据变成跟随深浅色主题的 SVG 图表：

- `vbarchart` 柱状图、`vpie` 饼状图、`vline` 折线图
- **转换为图表** 命令自动识别表头类型；检测到图表表头时，表格右下角还会贴一个**小图标按钮**，点击即可转换，无需跳出表格
- 图表模板可从设置面板一键添加（中文/英文各一套，附示例内容）
- **组合图表**：任意数量的柱状图/折线图可放进同一张大表格，渲染成一张融合图表——折线按类目对齐叠在柱子上，多柱段槽内并排。y 轴量程取所有段 y范围 的下界最小值与上界最大值（如 0-3 与 1-5 → 0-5）；标题与 x/y 轴名称取最左侧段的值。表格为纵向拼合，每段占两列（左列=类型/类目，右列=数值），第一行在各段左列并排声明类型（`vbarchart`/`vline`，数量不限），各段在自己的两列里填配置行（`y范围`、`y` 可多段同行并排）与数据行（类目｜数值），`v%` 行放整表最后。没有现成组合模板——用选取/移动把两类单表拼成一张即可

### 转换

- Markdown 表格或 HTML 表格 → Vtable
- Vtable → Markdown 表格或 HTML 表格
- 所有编辑自动保存回代码块源码

### 储存格式

表格存放在 ` ```vtable ` 代码块内，序列化为 JSON，所有状态都能完整往返保存：

- 每个单元格存内容 + `rs`/`cs`（纵向/横向合并跨度）+ 可选的对齐与底色
- 额外字段保存单表状态：显示模式、RC 模式列宽行高、单表线型与斑马纹覆盖
- 单元格内容为 Markdown，必要时混存行内 HTML；换行以 `<br>` 存储
- 公式只存原式（`=SUM(A1:B2)`），渲染时求值
- 每次编辑自动写回代码块；直接粘进代码块的原生 Markdown 管道表格也能被解析转换

### 快捷键与命令

以下快捷键与手势均为内置，开箱即用，无需任何配置。

| 效果 | 快捷键 |
| --- | --- |
| 框选单元格区域 | Ctrl/Cmd+Shift + 按住拖动 |
| 选中（或追加选中）单个单元格 | Ctrl/Cmd+Shift + 点击 |
| 选中整行 / 整列 | 单击行号 / 列标（RC 模式） |
| 把整行 / 整列加入选框（多选） | Shift + 单击行号 / 列标 |
| 清除选框 | 在选框外普通单击 |
| 格内文字全选并转为选框 | Ctrl/Cmd+A |
| 复制选框为 Markdown 表格 | Ctrl/Cmd+C |
| 粘贴 Markdown 表格（以焦点格为左上角覆盖） | Ctrl/Cmd+V |
| 粘贴 Markdown 表格并按需扩行 / 扩列 | Ctrl/Cmd+Alt+V |
| 清空选区内单元格内容 | Backspace / Delete |
| 删除选框对应的整行 / 整列（非整行列仅提示） | Ctrl/Cmd+Delete（Mac 键盘 Cmd+Backspace 同效） |
| 删除光标所在行（macOS / iPad 妙控键盘） | Cmd+Backspace |
| 把选中文本包裹为加粗（`**...**`）——仅格内编辑 | Ctrl/Cmd+Alt+B |
| 撤销上一次格内编辑 | Ctrl/Cmd+Alt+Z |
| 下一格 / 上一格 | Tab / Shift+Tab |
| 单元格间移动（对称落点） | ↑ ↓ ← → |

所有命令都可在 Obsidian 设置中绑定自定义快捷键，包括创建、转换、图表生成、样式、斜分与模式切换。

### 行内代码行为

- 行内代码（反引号）内容**按字面显示**：反引号内的 HTML（如标签）显示为纯文本而不被渲染，编辑时与光标离开格子后均如此
- 单元格内不支持三反引号跨行代码块；围栏源码一律按普通文本显示与编辑

### 浮动工具栏

焦点格旁出现两行工具栏：加粗、斜体、字号、合并/拆分、增删行列，以及一键导出。桌面端与移动端可分别开关。

### 右键菜单

快速插入/删除行列、合并与拆分单元格、复制/粘贴/剪切/删除，以及模式切换。

#### 自定义右键菜单

右键菜单完全可在 **设置 → vtable → 右键菜单自定义** 中定制：

- **文本模式**：每行一条菜单项；`---` 插入分隔线；`cmd:命令ID` 插入任意 Obsidian 命令；末尾追加 `|图标名`（Lucide 图标名）可覆盖该项图标。
- **查找助手**：输入关键词过滤 vtable 动作与全部 Obsidian 命令，点击选择，可再填图标名，然后复制生成的行粘贴进文本框。
- 点击 **保存** 立即对所有表格生效。内置动作 id：`vt.copy`、`vt.paste`、`vt.cut`、`vt.delete`、`vt.clearContent`、`vt.bold`、`vt.italic`、`vt.alignL`、`vt.alignC`、`vt.alignR`、`vt.alignT`、`vt.alignM`、`vt.alignB`、`vt.pickColor`、`vt.insRowAbove`、`vt.insRowBelow`、`vt.delRow`、`vt.insColLeft`、`vt.insColRight`、`vt.delCol`、`vt.mergeRight`、`vt.mergeDown`、`vt.split`、`vt.modeOL`、`vt.modeHS`、`vt.modeRC`。

### 设置

- 界面语言（中文 / English；选英文时浮动工具栏缩写在设置内附图例说明）。命令名跟随界面语言——切换后请重新加载插件
- 桌面端 / 移动端浮动工具栏分别开关
- 显示 OL/HS/RC 模式切换按钮
- **交互组件开关**：填充柄 / 行列拖动符 / 图片缩放拖柄分别可关（默认全开）
- **表格样式**（折叠面板）：表格外角圆角；表头底色（主题色或自定义）；线型预设（三线表 / 无格线 / 仅横线）带全局开关；隔行变色（主题色或自定义色，选自定义时展示取色器）——外加表头底色与隔行变色的单表命令
- 导出：Markdown 导出时以嵌套 HTML 标签保留对齐与底色
- 可自定义右键菜单（见上）

## 使用方法

1. 在命令面板（`Ctrl/Cmd+P`）运行 **创建 vtable**，或用 **转换为 vtable** 把现有 Markdown/HTML 表格转成 Vtable
2. 点击任意单元格开始编辑；按 Enter 在格内换行
3. 一切内容以 JSON 存储在 ```vtable 代码块中——笔记保持可迁移

## 安装

### 从官方社区插件市场（推荐）

在 Obsidian 中打开 **设置 → 第三方插件 → 浏览**，搜索 **Vtable** 安装，更新会通过 Obsidian 自动推送。

### 通过 BRAT

1. 安装 **BRAT** 社区插件
2. 在 BRAT 设置中选择 *Add beta plugin*
3. 输入 `https://github.com/Ming145/Vtable`
4. 在社区插件中启用 Vtable

### 手动安装

1. 从最新 [Release](https://github.com/Ming145/Vtable/releases) 下载 `main.js`、`styles.css` 与 `manifest.json`
2. 在仓库中创建 `.obsidian/plugins/vtable/` 文件夹
3. 将三个文件复制进去
4. 重载 Obsidian 并在社区插件中启用 **Vtable**

## 从源码构建

```bash
git clone https://github.com/Ming145/Vtable
cd Vtable
npm install
npm run build
```

然后把 `main.js`、`styles.css` 与 `manifest.json` 复制到 `.obsidian/plugins/vtable/`。
